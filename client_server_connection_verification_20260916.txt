H5 client/server connection verification — 2026-09-16

Phạm vi
- Client Android package: com.langla.net trên LDPlayer serial emulator-5554.
- Server/zone được kiểm tra: center_0 và local_1 (symlf_1).
- Các giá trị IP, tài khoản và thông tin truy cập được redact trước khi commit.

Phát hiện ban đầu
- Client tải được cấu hình HTTP nhưng hiển thị lỗi kết nối chung.
- HTTP config, role API và gonggao API trả HTTP 200.
- Nguyên nhân chính: các zone game chưa chạy, nên các cổng game tương ứng chưa listen.

Thao tác
- Khởi động sszg_center_0 bằng ctl.sh start.
- Khởi động sszg_symlf_1 bằng ctl.sh start.
- Không khởi động các zone khác vì client đang map vào symlf_1 và chưa có bằng chứng cần mở rộng.
- Thực hiện reconnect trên client.
- Đăng nhập bằng tài khoản test đã có sẵn trong client để kiểm tra toàn bộ flow.

Bằng chứng sau xử lý
- Client phát sinh POST role API cho server đã redact với HTTP 200.
- Client phát sinh GET gonggao.php với HTTP 200.
- Client chuyển khỏi popup lỗi, vào giao diện game và hiển thị hộp Tin tức; sau khi xác nhận, giao diện game chính hiển thị.
- Server có BEAM process cho center_0 và local_1, chạy từ Erlang/OTP 19.2 đã cài.
- Listener phân phối Erlang hoạt động trên 40100/40101.
- Listener game hoạt động trên 9000/9001.
- Log local_1 ghi nhận kết nối tới central server thành công và đồng bộ thông tin.

Kết luận
- Client đã kết nối thành công tới server ở cả lớp HTTP và game flow.
- Lỗi trước đó do game zone chưa được khởi động, không phải lỗi IP/SSH hay HTTP 403 của client.
- Các dòng lỗi nghiệp vụ cũ trong log zone (timer/white_acc.cfg) không ngăn việc khởi động listener hoặc đăng nhập đã kiểm chứng.

Chưa thực hiện
- Không thay đổi mã nguồn/APK.
- Không mở các zone symlf_2, symlf_3, symlf_4 vì chưa cần cho client hiện tại.
